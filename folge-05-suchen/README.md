# Folge 5: Suchen und eigene Transformationen

Alle Quellen durchsuchen und Dokumente automatisch zusammenfassen

▶ Video: folgt

## Was du lernst

- Text- und Vektorsuche über alle Notebooks
- Wofür Fragen (Beta) gedacht ist
- Eine eigene Transformation mit Prompt anlegen
- Eine Transformation auf eine Quelle anwenden

## Voraussetzungen

- Ein laufendes Open Notebook: [Open Notebook starten](../README.md#open-notebook-starten)
- Ein Notebook mit Quellen (Folge 3)

## Datenschutz

Suche und Transformationen laufen mit Ollama komplett auf deinem Rechner. Mit einem Cloud-Modell geht bei jeder Transformation der ganze Text der Quelle an den Anbieter. Keine Rechtsberatung.

## Zum Kopieren

**Prompt für die Transformation „Kernaussagen“**

```
Fasse die Quelle in genau fünf kurzen Stichpunkten auf Deutsch zusammen. Nutze nur Fakten aus der Quelle, mit Zahlen, wo es welche gibt.
```
