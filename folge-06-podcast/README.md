# Folge 6: Podcast aus deinen Quellen

Zwei KI-Stimmen besprechen deine Dokumente, auf Deutsch

▶ Video: folgt

## Was du lernst

- Warum ein Podcast ein Text-to-Speech-Modell braucht
- Ein Sprecherprofil mit zwei Stimmen anlegen
- Ein Folgenprofil auf Deutsch einrichten
- Einen Podcast aus einem Notebook erzeugen und anhören

## Voraussetzungen

- Ein laufendes Open Notebook: [Open Notebook starten](../README.md#open-notebook-starten)
- Ein Notebook mit Quellen (Folge 3)
- Ein API-Schlüssel von OpenAI (in Open Notebook unter Modelle eintragen, Folge 2)

## Datenschutz

Für den Podcast gehen die ausgewählten Quellen an OpenAI in den USA: zuerst an ein Sprachmodell, das das Drehbuch schreibt, dann der Text an die Sprachausgabe. Nimm dafür keine vertraulichen oder personenbezogenen Unterlagen ohne passende Grundlage (Auftragsverarbeitung, Drittlandübermittlung). Lokal geht es mit einem eigenen Sprachserver, siehe Open-Notebook-Doku „Local TTS“. Keine Rechtsberatung.

## Zum Kopieren

**Briefing für das Folgenprofil**

```
Erkläre die wichtigsten Inhalte locker und kurz auf Deutsch.
```
